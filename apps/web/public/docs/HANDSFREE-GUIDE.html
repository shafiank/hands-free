âš™ï¸ Token Compressor

An intelligent system prompt compression tool that reduces API costs by condensing lengthy system prompts without losing critical functionality.

Three Compression Levels

Full
Complete system prompt with all context and behavior guidelines. Highest quality, highest token cost.
Compact
Essential instructions only. ~50% token reduction while maintaining core functionality.
Minimal
Ultra-condensed core directives. ~70% token reduction for cost-sensitive workflows.

Configure in Settings

Smart Retention

The compressor intelligently retains safety guidelines, identity preferences, and critical logic while removing verbose explanations. Token savings compound across long conversations.
